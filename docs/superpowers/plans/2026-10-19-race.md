# Traffic Race Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Candy-Crush-style race (you + 4 cartoon rivals, first to 6 new-level wins, 3 race hearts, 24 h) that unlocks after L30.

**Architecture:** Pure rules in `src/game/race.js` (no Pixi, no storage, seeded RNG), persisted as one `race` object on `ProgressManager`; GameApp calls it at the existing win / final-loss / quit / rescue / map hook points; a new Pixi `RaceScreen` card plus small additions to the map, win screen, rescue overlay and lose screen.

**Tech Stack:** plain ES modules, PixiJS 8 screens (PremiumUI / ToyStyle helpers), Vitest.

**Spec:** `docs/superpowers/specs/2026-10-19-race-design.md`

## Global Constraints

- Unlock after beating L30; goal 6 frontier wins; 3 hearts; 24 h; 4 rivals; first race rivals x1.35 slower.
- Prizes: 1st 500 coins + 2 colorChange + 2 freeze + 2 bombs; 2nd 150 + 1 freeze; 3rd 50; 4th-5th 20; out / timeout 0.
- Only the frontier level (levelId === progress.unlockedLevel, numbered, not daily) counts or costs.
- Rivals are named cartoon racers; nothing claims they are real or online.
- Ads never required: the coins continue and walking away always remain.
- `docs/VISION.md` untouched; popups through the existing modal/screen paths, no ad-hoc spawning.

## Review Focus

- A saved race object that is corrupt / from an older shape: `sanitizeRace` returns null, never throws.
- Time passes while the app is closed: `syncRace(now)` caps rival drift at `endsAt` and ends the race as timeout.
- A level result after `endsAt`: does not count; race resolves as timeout first.
- Fewer than 6 unbeaten levels left: no START offered; an active race whose frontier runs out ends as timeout at expiry (no crash).
- Replaying an old level during a race: no win, no heart, rivals do not move.

### Task 1: Race rules module

**Files:** Create `src/game/race.js`; Test `tests/race.test.js`

**Interfaces — Produces:**
- `RACE_UNLOCK_AFTER = 30, RACE_GOAL = 6, RACE_HEARTS = 3, RACE_MS = 86_400_000, RACE_PRIZES` (array index = place-1: `{ coins, boosters }`)
- `raceUnlocked(unlockedLevel) -> bool` (unlockedLevel > 30)
- `canStartRace(unlockedLevel, levelCount, beatenFinal) -> bool` (unlocked, and ≥ 6 unbeaten levels remain)
- `startRace({ now, seed, first }) -> race`
- `syncRace(race, now) -> race` (drift + timeout)
- `recordRaceAttempt(race, { won, now, rng? }) -> { race, events: string[] }` events ⊂ `['win','heart','finished','out','timeout']`
- `raceStandings(race) -> [{ name, color, wins, progress, you, finished }]` sorted
- `racePrize(race) -> { coins, boosters } | null`
- `sanitizeRace(obj) -> race | null`
