1. TINY MOTORBIKES — FIXED
===============================================================================
L1, L2 and L3 were still gridRows 16. Every other level is 8.

Car size is FIT x rowPitchWu x pxPerWu and rowPitchWu = 26/gridRows, so:
    gridRows 16 -> rowPitch 1.625 wu
    gridRows  8 -> rowPitch 3.250 wu
Exactly double. L1-L3 rendered every car at HALF the size the rest of the game
uses. They were held back as out of scope during both the L4-L8 pilot and the
L9-L40 conversion, and were the last levels on the old board.

Sim after (400 runs): L1 100.0%, L2 97.3%, L3 92.3%, all in the 85-100 band. The
40-level flag set is unchanged (L4 TOO EASY, L30 BOSS, L39 TOO HARD) — nothing
else moved. The gridRows invariant in regression-level-start.test.js loses its
exception and is now simply 8 for every level.

===============================================================================
2. THE FTUE HAND — FIXED, BY REPAIRING THE ASSET
===============================================================================
This was never a code bug. public/sprites/ui/icon-hand.png shipped 128x128 with
its opaque content spanning y 0..127 — zero padding — and the index fingertip was
a FLAT 40px-wide column from y=0 to y=3 with no outline across the top. Measured
row by row: a drawn fingertip tapers over ~15-20px; this one did not taper at all.
Those pixels were not in the file.

I closed the shape the existing art already defines rather than drawing new art.
The source's own geometry and colours, measured off row y=2:
    white outer stroke  x 17..56  -> radius 19.5 about cx 36.5
    dark outline        x 21..54  -> radius 16.5
    cream fill          x 24..51  -> radius 13.5
The cap is composited UNDERNEATH the original, so the original's pixels win
everywhere they exist and only the missing tip is new. See 03: the repaired tip
has the dark outline wrapping it, matching every other edge of the hand.

The cuff at the bottom was also cut (a flat 22px edge at y=127) but was already
tapering to a near-point, so it got padding rather than a cap — an added ellipse
read as a white nub hanging off the wrist, which looked worse than the flat it
was closing. Tried, looked wrong, removed.

Result: 128x128 with gaps top 1 / bottom 8 / left 15 / right 16, in line with
icon-car and icon-book (13-15px). Script kept at scripts/_repair-hand-icon.mjs.
Fixes both call sites — TutorialOrchestrator uses the same icon at size 28.
